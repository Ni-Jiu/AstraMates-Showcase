# 前端模块

前端基于 Vue 3 + Vite + Pinia。

## 页面

```text
assistant/   总管 AI
create/      角色创建
friend/      单聊
groupchat/   群聊
homepage/    首页
user/        登录、注册
```

## 交互

- Markdown / LaTeX 渲染
- SSE 流式消息
- 图片、文档、语音输入
- 聊天记录导出
- 群聊/单聊模型选择
