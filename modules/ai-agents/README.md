# AI 角色模块

AI 角色是 AstraMates 的核心对象。

## 角色能力

- 名称、头像、背景
- 人物设定
- 声音配置
- 对话风格
- 角色关系

## 角色在群聊中的行为

- 根据设定参与讨论
- 被 @ 或点名时优先参与
- 由调度器决定是否补充
- 生成失败时可被跳过

## 能力匹配

调度评估会参考角色的：

```text
身份
职业
擅长领域
知识背景
```

角色简介越清晰，专业问题越容易被正确分配。
