# 调度模块

群聊调度器负责回答三个问题：

```text
谁适合说
谁值得补充
什么时候结束
```

## 流程

```text
本地粗筛
  ↓
批量评估
  ↓
综合分排序
  ↓
确定发言顺序
  ↓
流式生成
  ↓
补充评估
  ↓
结束
```

## 关键规则

- 硬点名 > @ > 软点名 > 普通调度
- 首位与补充使用不同权重
- 动态人数，不强制凑满
- 第一遍去重
- 第二遍只允许高价值重复
- 评估失败使用缓存或本地分兜底
